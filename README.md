# Weather App

A full-stack weather application built with React, Node.js, Express, and TypeScript. The application uses the OpenWeather API to fetch and display current weather information for different cities.

## Features

- Search weather by city name
- Display temperature and feels-like temperature
- Display weather condition and description
- Display humidity and wind speed
- Display weather icons
- Search using the Enter key
- Loading state while fetching weather
- Invalid city error handling
- Empty input validation
- Responsive user interface

## Technologies Used

### Frontend
- React
- JavaScript
- Axios
- CSS

### Backend
- Node.js
- Express
- TypeScript
- Axios

### API
- OpenWeather API
